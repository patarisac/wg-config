Panduan cepat

Cara pakai

Setelah konfigurasi dibuat, ikuti langkah berikut untuk menjalankan WireGuard di server Linux dan menghubungkan profil client dari ponsel.

  1. 1

    Install WireGuard di server Linux

    Jalankan perintah berikut pada server Debian atau Ubuntu.

    sudo apt install wireguard
  2. 2

    Simpan konfigurasi server

    Salin hasil konfigurasi Server dari generator ke file /etc/wireguard/wg0.conf.

    sudo nano /etc/wireguard/wg0.conf
  3. 3

    Amankan lalu jalankan tunnel

    Batasi izin file konfigurasi, kemudian aktifkan interface wg0.

    sudo chmod 600 /etc/wireguard/wg0.conf sudo wg-quick up wg0
  4. 4

    Verifikasi koneksi server

    Cek interface, public key, listening port, dan peer yang sudah terdaftar.

    sudo wg
  5. 5

    Import profil client dari QR

    Di aplikasi WireGuard ponsel, tambahkan tunnel baru lalu pilih Create from QR code. Pindai QR Code dari kartu Client yang dihasilkan aplikasi ini.

  6. 6

    Nama dan aktifkan tunnel

    Berikan nama tunnel, simpan, lalu aktifkan tombol koneksi WireGuard.

  7. 7

    Setup proxy listener Burp Suite

    Di Burp Suite, buka Proxy settings lalu tambahkan proxy listener baru. Pada tab Binding, isi Bind to port dengan nilai yang sama seperti Burp Suite Port di generator, lalu pilih All interfaces.
